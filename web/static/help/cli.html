CLI installieren & nutzen

tvcli spricht Ihre TeamVault-Instanz an. Secrets werden nur lokal entschlüsselt (Zero-Knowledge).

Hilfe Vault Extension Installation Nutzen

Installation (Einzeiler)

Voraussetzung: Admin hat die Binaries unter /downloads/ abgelegt (siehe Hinweis unten).

Windows (PowerShell)

Linux / macOS (Bash)

Das Skript wählt amd64 oder arm64 automatisch und legt tvcli nach ~/.local/bin (PATH ggf. ergänzen).

Manuell

  1. Passende Datei von /downloads/ holen (z. B. tvcli-windows-amd64.exe).
  2. Windows: irgendwohin legen und in der PowerShell aufrufen.
  3. Linux: chmod +x tvcli-… und nach ~/.local/bin/tvcli kopieren.
