Vault – Kurzanleitungen

Secrets anlegen, teilen und importieren — Ver-/Entschlüsselung nur im Browser (Zero-Knowledge).

Anlegen Teilen Import

Secret anlegen

Schritte

  1. Anmelden und Vault mit dem Master-Passwort entsperren.
  2. Sidebar Neu anlegen öffnen.
  3. Titel, optional Tags, Benutzername und Passwort eintragen.
  4. Passwort per Generator erzeugen oder manuell setzen.
  5. Weitere Felder über Feld hinzufügen: Website, TOTP-Seed, Notizen, SSH-Keys, …
  6. Optional User/Gruppen zum Teilen wählen (nur onboardete Ziele).
  7. Speichern — der Server speichert nur Ciphertext.

Secrets teilen

Teilen erfolgt explizit pro Person oder Gruppe mit eigenem Umschlag — kein gemeinsames Gruppenpasswort. Die Listen-Spalte Gruppen zeigt nur freigegebene Gruppen, nicht Ihre Mitgliedschaften.

Zugriff vergeben

  1. Secret Öffnen → Bereich Zugriff.
  2. User oder Gruppe links anklicken oder nach rechts ziehen.
  3. Empfänger sieht den Eintrag unter Geteilt mit mir.

Zugriff entziehen

  1. Bei einem Eintrag rechts Entfernen (oder zurück nach links ziehen).
  2. Der Datenschlüssel wird rotiert; der alte Umschlag wird ungültig.

Import und Anlegen ohne Auswahl erzeugen keine Freigaben.

Neue Gruppenmitglieder erhalten Gruppen-Secrets automatisch nachgeteilt, sobald jemand mit Zugriff den Vault entsperrt hat (Zero-Knowledge).
