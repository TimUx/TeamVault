Vault – Kurzanleitungen

Secrets anlegen, mit Kollegen teilen und Einträge aus anderen Passwortmanagern übernehmen — alles verschlüsselt im Browser (Zero-Knowledge).

Hilfe Anlegen Teilen Import CLI Extension

Secret anlegen

Schritte

  1. Anmelden und Vault mit dem Master-Passwort entsperren.
  2. Sidebar Neu anlegen öffnen.
  3. Titel, optional Tags (Komma-getrennt), Benutzername und Passwort eintragen.
  4. Passwort per Generator erzeugen (Länge/Symbole einstellbar) oder manuell setzen.
  5. Weitere Felder über Feld hinzufügen: Website (URL), TOTP-Seed, Notizen, SSH-Keys, S3-Keys, Zertifikat, Freitext.
  6. Optional direkt User oder Gruppen zum Teilen auswählen (nur onboardete Ziele).
  7. Speichern — Titel und Inhalt werden im Browser verschlüsselt; der Server speichert nur Ciphertext.

Beispiel (VPN-Zugang)

TitelVPN Firmenzugang
Tagsvpn, remote, prod
Benutzernamemax.mustermann@firma.de
Passwortper Generator (z. B. 20 Zeichen, Symbole an)
Website (URL)https://vpn.firma.de
NotizenPortal-2FA über Authenticator-App

TOTP: Seed als base32 oder otpauth://totp/… unter Feld hinzufügen → TOTP-Seed. Mehrere URLs sind möglich (wichtig für die Browser-Extension).

Secrets teilen

Teilen erfolgt pro Person oder Gruppe mit eigenem Verschlüsselungsumschlag — es gibt kein gemeinsames Gruppenpasswort.

Mit einem Benutzer teilen

  1. Secret in der Liste Öffnen (Detail-Modal).
  2. Unter Teilen mit User den Empfänger wählen (nur onboardete User mit Public Key).
  3. Teilen klicken — der Datenschlüssel wird für diesen User neu verpackt.
  4. Der Empfänger sieht den Eintrag unter Geteilt mit mir.

Beispiel: Sie legen „Datenbank Staging“ an und teilen mit dba.team — nur dieser User kann entschlüsseln.

Mit einer Gruppe teilen

  1. Secret öffnen → Bereich Teilen mit Gruppe.
  2. Gruppe wählen (z. B. Team Infrastruktur) → Gruppe teilen.
  3. Jedes Gruppenmitglied erhält einen eigenen Umschlag; neue Mitglieder brauchen ggf. erneutes Teilen durch einen Admin.

Gruppen werden in der Administration gepflegt. Zugriff entziehen: Zugriff entziehen + rotieren im Secret-Detail (alter Schlüssel wird ungültig).

Beim Anlegen direkt teilen

Unter Neu anlegen können Sie vor dem ersten Speichern User und Gruppen auswählen — praktisch für Einträge, die von Anfang an im Team liegen sollen.

Import aus Fremdtools

Sidebar Import → Datei wählen → Vorschau prüfen → gewünschte Zeilen anhaken → Auswahl importieren. Parsing und Verschlüsselung laufen nur im Browser.

Unterstützte Formate

  • Bitwarden — JSON-Export (Login-Einträge, type: 1)
  • KeePass — XML-Export (nicht .kdbx direkt)
  • KeePassXC — CSV
  • Chrome / Edge — Passwort-CSV
  • Firefox — CSV
  • LastPass — CSV
  • 1Password — CSV oder 1PUX (export.data im JSON)
  • Proton Pass — JSON
  • TeamVault — JSON oder verschlüsselte .tvbak (Backup-Passwort nötig)
  • Generisches CSV — Spalten title, username, password, url, notes, tags

Beispiel: Bitwarden JSON (Auszug)

In Bitwarden: Werkzeuge → Export → Dateiformat .json. Mindestens ein Login-Eintrag:

{ "items": [ { "type": 1, "name": "Beispiel Weblogin", "login": { "username": "user@example.com", "password": "AltesPasswort123!", "uris": [{ "uri": "https://app.example.com/login" }] }, "notes": "Optional" } ] }

Beispiel: KeePassXC CSV

Export als CSV; erste Zeile mit Spaltenüberschriften:

"Group","Title","Username","Password","URL","Notes","TOTP" "Arbeit","Intranet","max","geheim42","https://intranet.firma.de","", "Arbeit","VPN","vpn-user","***","https://vpn.firma.de","nur Büro"

Beispiel: Chrome / Edge CSV

Einstellungen → Passwörter → Export. Typische Spalten:

name,url,username,password Beispiel Portal,https://portal.firma.de/,max.mustermann,Geheim123 Altes Tool,https://legacy.app/,admin,legacy-pass

Beispiel: Generisches CSV

Für eigene Tabellen oder konvertierte Listen — Header in Kleinbuchstaben:

title,username,password,url,notes,tags Staging DB,dbadmin,Db-Secret-2024,,nur intern,db,staging API Schlüssel,,sk_live_xxx,,Rotieren Q2,api

Beispiel: 1Password 1PUX

Export als .1pux oder JSON mit verschachteltem export.data. TeamVault liest die Login-Items aus der 1Password-Struktur — kein manuelles Umbauen nötig, sofern der offizielle Export verwendet wird.

Tipps nach dem Import

  • Vorschau nutzen: nur benötigte Einträge importieren (Häkchen setzen).
  • .tvbak ist verschlüsselt — zuerst Backup-Passwort eingeben und Sicherung entsperren.
  • Tags aus dem Quellformat werden übernommen, wo vorhanden.
  • Mehrere URLs aus Bitwarden landen als Website-Felder (Extension-Fill).
  • Klartext-Exporte aus dem Quell-Tool sicher löschen, wenn nicht mehr nötig.
