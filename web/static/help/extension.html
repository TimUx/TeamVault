  1. about:debugging#/runtime/this-firefox → temporäres Add-on laden → manifest.json.

Schritt 3 · Fill & Copy

  1. Website öffnen, die zur Secret-URL passt (falls URLs hinterlegt).
  2. Popup → optional Alle / Privat / Geteilt filtern → Eintrag → Fill oder Copy.

Secrets ohne URL: Fill/Copy immer erlaubt. Mit URL: nur bei Domain-Match (Phishing-Schutz).
