Installation Fallback Nutzen

Installation

Voraussetzung Chrome / Edge

Die normale Installation braucht eine Browser-Richtlinie (ExtensionSettings + ExtensionInstallSources). Ohne diese Richtlinie lädt der Browser die .crx nur herunter — er installiert sie nicht.

In Firmenumgebungen blockiert die GPO oft Schreibzugriff auf HKCU\Software\Policies. Dann muss die IT die Richtlinie zentral setzen (HKLM/GPO/Intune) oder Sie nutzen den Entwicklermodus.

Normal installieren (empfohlen)

Einmal Einrichtung, Browser neu starten, dann installieren — ohne Entwicklermodus.

Firefox

TeamVault liegt nicht im Mozilla-Add-on-Store. Zwei Wege:

  1. Temporär (Test): ZIP entpacken (teamvault-extension.zip) → about:debugging#/runtime/this-firefox → Temporäres Add-on laden → manifest.json im entpackten Ordner. Gilt bis zum nächsten Firefox-Neustart.
  2. Dauerhaft (Firma): IT verteilt teamvault-extension.xpi per Firefox-policies.json (Vorlage: firefox-policy.json, Add-on-ID teamvault@local). Oft nötig: xpinstall.signatures.required = false in den Policies.

Erweitert: Entwicklermodus (Fallback)

Nur wenn die normale Installation nicht möglich ist (z. B. ohne Browser-Richtlinie):

ZIP entpacken und manuell laden — Einzeiler:

  1. Chrome/Edge: chrome://extensions → Entwicklermodus → Entpackte Erweiterung laden.
  2. Firefox: about:debugging#/runtime/this-firefox → temporäres Add-on.

Schritt 2 · Login & Unlock

  2. Master-Passwort — nur lokal in der Extension.

Schritt 3 · Fill & Copy

  1. Website öffnen, die zur Secret-URL passt (falls URLs hinterlegt).
  2. Popup → optional Alle / Privat / Geteilt filtern → Eintrag → Fill oder Copy.

Secrets ohne URL: Fill/Copy immer erlaubt. Mit URL: nur bei exakter Origin-Match (Schema, Host und Port — Phishing-Schutz).

In der Web-App: Konto & Sicherheit → Clients — gleiche Downloads und Einzeiler (wenn Extension-Integration aktiviert).
