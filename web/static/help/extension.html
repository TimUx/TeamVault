Hilfe Vault CLI Installation Nutzen

Installation

Einzeiler (Windows PowerShell)

Lädt das Extension-Paket (falls unter /downloads/ bereitgestellt) und zeigt den Zielordner.

Einzeiler (Linux / macOS)

Chrome / Edge (manuell)

  1. Extension-Ordner bereitlegen (Einzeiler oben oder aus dem Git: clients/extension).
  2. chrome://extensions bzw. edge://extensions öffnen.
  3. Entwicklermodus einschalten → Entpackte Erweiterung laden.
  4. Den Ordner wählen (der die manifest.json enthält).

Firefox (manuell)

  1. about:debugging#/runtime/this-firefox öffnen.
  2. Temporäres Add-on laden → manifest.json im Extension-Ordner wählen.
  3. Hinweis: temporäre Add-ons verschwinden nach Neustart von Firefox (für Dauerbetrieb signiertes XPI oder Entwickler-Profil nötig).

Einrichten & nutzen

Schritt 1 · Server-URL

Im Extension-Popup die URL Ihrer Instanz eintragen:

Bei HTTPS-Server: in den Extension-Details die optionalen Host-Berechtigungen für Ihre Domain erlauben.

Schritt 2 · Login & Unlock

  1. Tenant, Benutzer, Login-Passwort (oder Passkey/TOTP wie in der Web-App).
  2. Master-Passwort eingeben — nur lokal in der Extension.

Schritt 3 · Fill & Copy

  1. Website öffnen, die zum Secret passt (URL im Eintrag hinterlegt).
  2. Extension-Popup → Eintrag wählen → Fill oder Copy.

Ohne passende Domain: Fill/Copy werden blockiert (Phishing-Schutz).

Admin: Extension-ZIP erzeugen und nach <data-dir>/downloads/teamvault-extension.zip legen — z. B. mit scripts/pack-clients.ps1.
