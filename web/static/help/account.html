TOTP, Passkeys und Offline-Vault

Beide schützen nur den Login. Der Vault bleibt immer Master-Passwort-pflichtig (Zero-Knowledge).

TOTP Passkeys Offline-Vault Beim Login

TOTP einrichten (Authenticator-App)

Ablauf

  1. Anmelden, Vault entsperren → Sidebar Konto & Sicherheit → Tab TOTP.
  2. TOTP einrichten klicken — der Server erzeugt ein Secret; der Browser zeigt einen QR-Code lokal (kein externes CDN) und die otpauth-URL.
  3. Authenticator-App (Microsoft Authenticator, Google Authenticator, Aegis, …) öffnen → Konto hinzufügen → QR scannen oder Secret/otpauth manuell einfügen.
  4. Den aktuellen 6-stelligen Code unter Code bestätigen eintragen → Aktivieren.
  5. Beim nächsten Login: zuerst Organisation, Username und Passwort (oder Passkey). Ist TOTP aktiv, folgt ein zweiter Schritt mit sechs Einzelfeldern für den Authenticator-Code.

Beispiel: so sieht der QR aus

Beispiel-otpauth (Demo-Secret, nicht produktiv):

otpauth://totp/TeamVault:max.mustermann?algorithm=SHA1&digits=6&issuer=TeamVault&period=30&secret=JBSWY3DPEHPK3PXP

In der App erscheint Ihr persönlicher QR neben der otpauth-URL. Nach dem Aktivieren wird das Secret nicht erneut angezeigt — bewahren Sie Backup-Codes Ihrer Authenticator-App sicher auf.

Was bedeutet die otpauth-URL?

issuerTeamVault (Anzeigename in der App)
accountIhr Username
secretBase32-Schlüssel (nur einmal sichtbar)
period / digits30 Sekunden, 6 Stellen (Standard)

Passkeys registrieren

Ablauf

  1. Konto & Sicherheit → Tab Passkeys.
  2. Namen vergeben (z. B. Notebook Windows Hello).
  3. Registrieren — Browser/OS-Dialog (PIN, Fingerabdruck, Sicherheitsschlüssel).
  4. Der Passkey erscheint in der Liste; löschen ist jederzeit möglich.

Kein TeamVault-QR für Passkeys: Die Einrichtung läuft über WebAuthn im Browser. Wenn Sie ein Smartphone als Authenticator nutzen, kann der Browser einen eigenen QR anzeigen — das steuert nicht TeamVault.

Voraussetzungen

  • HTTPS (oder localhost)
  • Unterstützter Browser (Chrome, Edge, Safari, Firefox aktuell)
  • Öffentliche URL / Relying-Party muss zur Instanz passen (Admin: Zugriff & Proxy)

Offline-Vault (optional)

Wenn der Administrator den Offline-Cache erlaubt, können Sie eine verschlüsselte lokale Kopie (nur Ciphertext, 30 Tage) vorhalten und ohne Netz lesen.

  1. Online anmelden, Vault entsperren.
  2. Offline-Kopie nach Entsperren aktualisieren aktivieren — Sync läuft im Hintergrund (Fortschritt in der Sidebar).
  3. Ohne Netz: Login-Seite Offline entsperren oder /app?offline=1 — nur Master-Passwort, kein TOTP.

Im Offline-Modus nur Lesen; Schreiben und Admin sind ausgeblendet. Logout löscht die Kopie nicht — unter Konto & Sicherheit Offline-Kopie löschen oder Opt-in deaktivieren.

Beim Login nutzen

  1. Schritt 1: Organisation wählen, Username, Login-Passwort (lokal: mindestens 16 Zeichen, Groß-/Klein, Ziffer, Sonderzeichen, keine Umlaute) — oder Button Passkey.
  2. Schritt 2 (nur bei aktivem TOTP): Sechs Einzelfelder für den Authenticator-Code — Auto-Weiter beim Tippen, Einfügen per Paste möglich. Zurück kehrt zu Schritt 1.
  3. Danach Vault mit dem Master-Passwort entsperren (oder Onboarding beim ersten Mal).

Ohne eingerichtetes TOTP entfällt Schritt 2. Passkey ersetzt nur das Login — ohne Master-Passwort kein Vault-Zugriff. CLI und Extension können TOTP optional im selben Formular mitschicken.
