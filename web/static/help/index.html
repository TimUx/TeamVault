Hilfe & Clients

Kurze Anleitungen für den Alltag: Web-App, Kommandozeile und Browser-Extension.

CLI (tvcli) Browser-Extension Login Vault öffnen

1 · Web-App

Im Browser anmelden → Vault mit Master-Passwort entsperren → Secrets nutzen. Einstieg: Login bzw. App.

2 · CLI

Für Skripte und Terminal: Binary installieren, einmal anmelden oder API-Key setzen, Secrets listen/lesen. Schritt für Schritt

3 · Extension

Chrome, Edge oder Firefox: Extension laden, Server-URL setzen, im Popup entsperren, Fill/Copy auf passenden Seiten. Schritt für Schritt

Diese Seiten laufen auf Ihrer TeamVault-Instanz (). Markdown-Fassungen liegen im Git unter docs/cli-guide.md und docs/extension-guide.md.
